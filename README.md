# Network-Defense-Against-Simulated-Attacks-Lab
This repo documents Lab 02: Defending the Network from a Simulated Attack, from the Network Security, Firewalls, and VPNs (3rd Edition) course. The lab covers running an automated breach-and-attack simulation with Infection Monkey (including successful exploitation and lateral file movement), then manually exploiting a Shellshock vulnerability (CVE-2014-6271) on a Linux web server with Metasploit to gain a Meterpreter shell. Remediation steps include detecting and quarantining EICAR test malware with ClamAV and Windows Defender, patching the vulnerable Bash version to confirm the exploit no longer succeeds, and hardening the network perimeter by locking down pfSense firewall rules on the DMZ interface.
